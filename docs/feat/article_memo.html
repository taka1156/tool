                    書きかけの記事メモ（.md）または質問設定（.json）をドロップ、またはクリックして選択
                
    
                
                
    
                    Markdown を貼り付けて読み込む
                    
                    
    
                    
    AI の出力をそのまま貼ってかまいません（コードフェンスは外して読みます）。
    
                
    
                
    読み込むと現在の内容は置き換わり、未記入の項目から順番に質問します。frontmatter は今の質問設定（形式・項目）に合わせて読み、合わない項目は警告して値を残します。テンプレートにない見出しはそのまま保持して書き出します。
    
                
    
                
    
                    質問設定（JSON）を貼り付けて読み込む
                    
                    
    
                    
    AI の出力をそのまま貼ってかまいません（```json のコードフェンスは外して読みます）。
    
                
    
                
    
                    質問設定（JSON）の書き方
                    
    
                        
    読み込むと、形式、完全自由の frontmatter 項目（キー・型）、本文の質問と見出しが切り替わります。本文の項目がない設定は本文を変えません。本文から外れた項目の回答は残りますが、書き出しには含まれません。
    
                        
      
                            
    • version は 1
      • 
                            
    • format は zenn / qiita / free のどれか
      • 
                            
    • free の項目は、frontmatter: true と key と kind を持つ質問。どちらかがなければ無視されます
      • 
                            
    • kind は text / text_tags / url / number / date / datetime / bool / emoji_single / emoji_multi
      • 
                            
    • zenn / qiita の場合、frontmatter の項目は形式の固定項目なので、JSON の frontmatter 項目は読みません（本文の項目は読みます）
      • 
                            
    • 本文の項目は group: "本文" と heading（と level: 2 か 3）を持つ質問。heading がないものは本文に入りません
      • 
                        
    
                        
    例（完全自由・項目 2 つ）
    
                        
    {
  "version": 1,
  "format": "free",
  "questions": [
    { "frontmatter": true, "key": "title", "kind": "text",
      "id": "title", "group": "仕上げ", "label": "title",
      "question": "タイトル" },
    { "frontmatter": true, "key": "created_at", "kind": "datetime",
      "id": "created_at", "group": "仕上げ", "label": "created_at",
      "question": "作成日時" }
  ]
}
    
                        
    「質問設定を JSON で書き出し」で保存したファイルは、そのまま読み込めます。読み込み後は「取り込みの結果」に件数や除外された項目が出ます。
